# 🧮 Calculadora Web

Uma calculadora desenvolvida com **HTML, CSS e JavaScript**, como parte dos meus estudos em desenvolvimento web.

O projeto foi criado com o objetivo de praticar lógica de programação, manipulação do DOM, funções JavaScript e estilização com CSS.

## 🚀 Funcionalidades

- Operações de adição, subtração, multiplicação e divisão.
- Suporte a números decimais.
- Visor que apresenta a operação durante os cálculos.
- Botão AC para limpar os valores.
- Botão DEL para apagar o último caractere.
- Tratamento de divisão por zero.
- Utilização pelo teclado do computador.

## 💻 Tecnologias utilizadas

- HTML5 — Estrutura da aplicação.
- CSS3 — Estilização e layout.
- JavaScript — Lógica de programação e funcionalidades.

## 📂 Estrutura do projeto

```text
calculadora/
│
├── index.html
├── style.css
└── script.js
```

## ▶️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` com a extensão Live Server.
4. Utilize a calculadora diretamente no navegador.
